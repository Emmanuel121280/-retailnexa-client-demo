# RetailNexa Mobile Marketing Showcase

This repository contains a standalone, responsive static website for GitHub Pages.

## Publish

1. Put `index.html` in the repository root of the `main` branch.
2. In GitHub **Settings → Pages**, select **Deploy from a branch**, `main`, `/(root)`.
3. Open the resulting Pages URL and test on a phone.

## What works

Responsive marketing pages, searchable feature directory, business industry selector, preset local conversation demonstration, plan information and a GitHub Issues contact link.

## What does NOT work

No authentication, database, POS, payment processing, WhatsApp API, real AI, customer form submission or tenant-specific live data. This is a marketing site, **not** a production SaaS backend. Existing RetailNexa modules need separate code audit and deployment.

## Safety

Do not commit API keys, database passwords, Meta tokens or private customer data to a public repository. Use a secure PHP/MySQL hosting environment for the real app.

## Customization

Email contact is withheld pending mailbox delivery verification. GitHub Issues requires sign-in. Pricing is historical reference information and must be checked before being advertised as active.
